Na Voe, o campo chama-se **Tags** — funciona como uma etiqueta livre que você
cola num contato para organizar e depois filtrar.

## Como adicionar uma tag

1. Abra a conversa do contato no inbox
2. No painel lateral, vá até o campo **Tags**
3. Digite a tag e confirme — pode separar várias por vírgula

A tag é gravada em minúsculas e com hífen no lugar de espaço (ex: "cliente vip"
vira `cliente-vip`).

## Como remover

No mesmo campo, clique para remover a tag que não faz mais sentido — ela some
só daquele contato, sem afetar os demais.

## Importante: não existe um cadastro central de tags

Diferente de outras ferramentas, a Voe não tem uma "biblioteca de tags" do
workspace com cores fixas — cada tag é texto livre por contato. Combine com o
time um padrão de nomenclatura (ex: sempre em minúsculas, sem acento) para não
acabar com `cliente-vip`, `Cliente VIP` e `cliente vip` como três tags
diferentes.

## Usando tags para filtrar

No inbox, o filtro **Tags** permite selecionar uma ou mais tags já usadas nos
seus contatos e ver só as conversas correspondentes. Veja também
[Como usar os filtros de conversas](/ajuda/whatsapp/filtros-do-inbox).

## Não funcionou?

- **Criei a mesma tag duas vezes com grafia diferente** — elas contam como
  tags separadas no filtro; edite os contatos para padronizar.
- **Não encontro minha tag no filtro** — o filtro só lista tags que já existem
  em algum contato; confirme que ela foi salva corretamente.
