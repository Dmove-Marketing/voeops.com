A Voe oferece dois jeitos de conectar seu WhatsApp. Os dois funcionam bem — a
escolha depende do tamanho e da criticidade da sua operação.

## Comparação rápida

| | **WhatsApp Api Voe** | **WhatsApp Api Oficial** |
|---|---|---|
| Como conecta | QR Code, em 1 minuto | Configuração na Meta |
| Depende do celular ligado | Sim | Não |
| Custo por mensagem | Não tem | Cobrado pela Meta |
| Risco de bloqueio | Existe | Praticamente nulo |
| Selo de conta verificada | Não | Sim (possível) |
| Mensagem após 24h | Livre | Só com modelo aprovado |
| Ideal para | Começar, times pequenos | Volume alto, operação crítica |

## Escolha a Api Voe se…

- Você quer **começar hoje**, sem burocracia
- Seu volume de mensagens é baixo ou médio
- Você já usa esse número no celular normalmente
- Ainda está testando a Voe

É a opção mais rápida e a que a maioria dos clientes usa no início.

## Escolha a Api Oficial se…

- O WhatsApp é **crítico** para o seu negócio e não pode cair
- Você dispara **campanhas para muitos contatos**
- Você quer o **selo de verificação** da conta
- Já teve número bloqueado antes
- Você tem conta de negócios verificada na Meta

## O ponto que mais pesa na decisão

Na **Api Voe**, a conexão depende do seu celular estar ligado e com internet. Se
o aparelho desliga, o atendimento para até alguém reconectar.

Na **Api Oficial**, a conexão vive na Meta. O celular não importa.

Se uma hora sem WhatsApp custa caro para você, a Api Oficial paga a burocracia
inicial.

## Dá para trocar depois?

Sim. Você pode migrar de uma para outra a qualquer momento em
**Configurações → Canais**. Comece pela Api Voe e migre quando o volume crescer —
é o caminho que a maioria segue.
